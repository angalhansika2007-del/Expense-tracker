# Expense Tracker

## Project Description

The Expense Tracker is a simple command-line application developed in Python. It helps users record daily expenses, view all expense records, and calculate the total amount spent.

## Features

- Add new expenses
- View all expenses
- Calculate total expenses
- Menu-driven interface
- Beginner-friendly code

## Technologies Used

- Python 3

## How to Run

1. Save the file as `main.py`
2. Open the terminal.
3. Run:

```bash
python main.py
```
